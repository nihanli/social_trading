### Day 2–4 — Active Monitoring (9:30 AM and 3:30 PM ET daily)

- [ ] Streamlit → Signals — quality scores distributed above 0.6
- [ ] Grafana System Health — no RED alerts
- [ ] Review exit reasons on Trades page (TAKE_PROFIT should dominate)

### Day 5 (Friday) — Evaluation Gate

Run the performance calculation:

```bash
source .venv/bin/activate
python - <<'EOF'
import psycopg2, os
from dotenv import load_dotenv
load_dotenv()

conn = psycopg2.connect(
    host=os.getenv("DB_HOST", "localhost"),
    dbname=os.getenv("DB_NAME", "trading"),
    user=os.getenv("DB_USER", "trader"),
    password=os.getenv("DB_PASSWORD", "changeme"),
)
cur = conn.cursor()
cur.execute("""
    SELECT
        COUNT(*)                          AS trades,
        AVG(pnl_pct)                      AS mean_return,
        STDDEV(pnl_pct)                   AS std_return,
        AVG(pnl_pct) / NULLIF(STDDEV(pnl_pct), 0) * SQRT(252) AS annualised_sharpe,
        SUM(CASE WHEN pnl_pct > 0 THEN 1 ELSE 0 END)::float / COUNT(*) AS win_rate
    FROM trades
    WHERE closed_at >= NOW() - INTERVAL '5 days'
""")
row = cur.fetchone()
print(f"Trades:    {row[0]}")
print(f"Mean ret:  {row[1]:.4%}")
print(f"Sharpe:    {row[3]:.2f}")
print(f"Win rate:  {row[4]:.1%}")
conn.close()
EOF
```

**Gate: Sharpe ≥ 0.5 AND Win rate ≥ 45% AND ≥ 20 trades before proceeding to live.**
